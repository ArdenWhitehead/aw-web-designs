# A.W Web Designs Website Toolkit

This project contains the main A.W Web Designs website plus reusable website templates.

## Main Website

These files power the live A.W Web Designs website:

- `index.html` - Home
- `about.html` - About
- `services.html` - Services and packages
- `portfolio.html` - Portfolio
- `contact.html` - Contact and quote forms
- `style.css` - Main website styling
- `script.js` - Main website interactions
- `Images/` - Main website images

Live site:

`https://ardenwhitehead.github.io/aw-web-designs/`

## Template Library

Reusable website templates are stored in `Templates/`.

### Simple Website Templates

- `Templates/3-page-template/`
- `Templates/5-page-template/`
- `Templates/8-page-template/`

These are best for standard small business websites.

### Advanced Templates

- `Templates/advanced-commerce-template/`
- `Templates/advanced-carpentry-template/`
- `Templates/advanced-electrician-template/`
- `Templates/advanced-plumber-template/`

These are best for businesses that need more interaction, such as search, categories, quote lists, booking lists, profiles or cart-style behaviour.

## Suggested Workflow

When creating a new client site:

1. Choose the closest template folder.
2. Copy that folder into a new client project.
3. Rename the business, services, prices and colours.
4. Test locally.
5. Commit and push when ready.

## Git Commands

Check changes:

```bash
git status
```

Save changes:

```bash
git add .
git commit -m "Describe the update"
git push
```
