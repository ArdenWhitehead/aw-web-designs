# Advanced Commerce Template

This template is separate from the 3, 5 and 8 page website templates.

It is designed for future businesses that need more advanced interaction, such as:

- ecommerce stores
- booking-heavy service businesses
- product catalogues
- customer account areas
- searchable menus or service lists
- repeat-order workflows

Included interactions:

- search box that filters products
- category shortcut filters
- pet/profile style filtering
- cart drawer
- add-to-cart buttons
- profile modal
- buy-again shortcut

This is not a copy of any specific brand. It is a reusable layout inspired by larger retail websites with heavier navigation and shopping behaviour.
