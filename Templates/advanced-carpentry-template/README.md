# Advanced Carpentry Template

This template is separate from the 3, 5 and 8 page website templates.

It keeps the same advanced interaction style as the commerce template, but adapts it for a carpentry business.

Included interactions:

- service search
- project-type filters
- project shortcut cards
- quote list drawer
- add-to-quote buttons
- project profile modal
- repeat-job shortcut

Colour direction:

Warm timber, copper and teal. This avoids the original yellow/black reference palette while still feeling bold and trade-focused.
