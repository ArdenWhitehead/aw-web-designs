# Advanced Electrician Template

This template is separate from the 3, 5 and 8 page website templates.

It keeps the same advanced interaction style as the commerce template, but adapts it for an electrician business.

Included interactions:

- service search
- urgent/home/business job filters
- service shortcut cards
- quote list drawer
- add-to-quote buttons
- job profile modal
- rebook shortcut

Colour direction:

Electric lime, bright blue and deep navy. This creates a high-energy trade look without matching the original yellow/black reference palette.
