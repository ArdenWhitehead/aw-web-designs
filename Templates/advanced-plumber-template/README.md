# Advanced Plumber Template

This template is separate from the 3, 5 and 8 page website templates.

It keeps the same advanced interaction style as the commerce template, but adapts it for a plumbing business.

Included interactions:

- service search
- property/job filters
- service shortcut cards
- booking list drawer
- add-to-booking buttons
- property profile modal
- rebook shortcut

Colour direction:

Aqua, navy and coral. This gives the template a fresh plumbing identity while keeping the same interactive layout.
